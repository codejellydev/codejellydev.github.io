## 한국어

CodeJelly(이하 "개발자")는 모바일 게임 BounceOrBreak(이하 "앱")의 개인정보처리방침을 다음과 같이 안내합니다.

### 1. 수집하는 개인정보

앱은 개인정보를 수집하지 않습니다. 계정 생성, 로그인, 이름·이메일·위치 등 어떤 개인정보도 요구하거나 저장하지 않습니다.

### 2. 기기에 저장되는 데이터

앱은 최고 점수, 설정값 등의 게임 데이터를 사용자의 기기 안에만 저장하며, 개발자는 이 데이터에 접근할 수 없습니다.

### 3. 네트워크 통신

앱은 시작할 때 개발자가 게시한 설정 파일(공지와 최신 버전 정보) 하나를 내려받습니다. 이 요청에 개인정보나 기기 식별자는 포함되지 않으며, 개발자는 접속 기록을 수집하지 않습니다. 파일은 GitHub Pages에 호스팅되며, 서버 접속 기록은 GitHub의 개인정보처리방침을 따릅니다. 그 밖의 네트워크 통신은 하지 않습니다.

### 4. 제3자 서비스

앱은 광고, 분석, 소셜 로그인 등 제3자 SDK를 사용하지 않습니다.

### 5. 아동의 개인정보

앱은 어떤 연령의 사용자로부터도 개인정보를 수집하지 않습니다.

### 6. 방침의 변경

향후 광고 등 제3자 서비스를 추가할 경우 이 방침을 갱신하고 시행일을 변경합니다. 변경 내용은 이 페이지에 게시합니다.

## English

CodeJelly ("the developer") provides this privacy policy for the mobile game BounceOrBreak ("the app").

### 1. Personal data we collect

The app does not collect personal data. It does not require or store accounts, logins, names, email addresses, or location.

### 2. Data stored on your device

The app stores game data such as your best score and settings only on your device. The developer cannot access this data.

### 3. Network communication

On launch, the app downloads a single configuration file published by the developer (notices and the latest version number). The request carries no personal data or device identifiers, and the developer does not collect access logs. The file is hosted on GitHub Pages; server access logs are governed by GitHub's privacy policy. The app performs no other network communication.

### 4. Third-party services

The app does not use third-party SDKs such as advertising, analytics, or social login.

### 5. Children's privacy

The app does not collect personal data from users of any age.

### 6. Changes to this policy

If third-party services such as advertising are added in the future, this policy will be updated with a new effective date. Changes will be posted on this page.
